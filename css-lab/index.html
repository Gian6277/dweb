📚 Material de guía CSS

Regla CSS

selector {
  propiedad: valor;
}

El selector indica qué elemento se modifica. Las propiedades definen su presentación.

Selectores

h2 { ... }
.tarjeta { ... }
#titulo { ... }
nav a { ... }
main > section { ... }

Podés seleccionar por etiqueta, clase, id, descendencia o relación directa.

Modelo de caja

.card {
  margin: 20px;
  padding: 24px;
  border: 1px solid;
  border-radius: 12px;
}

Contenido, padding, borde y margen determinan el espacio que ocupa cada caja.

Flexbox

.contenedor {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 20px;
}

Útil para distribuir y alinear elementos en una dimensión.

Grid

.galeria {
  display: grid;
  grid-template-columns:
    repeat(3, 1fr);
  gap: 20px;
}

Permite construir diseños en filas y columnas.

Interacción

.boton:hover {
  transform: translateY(-2px);
}

Las pseudoclases permiten definir estados como :hover.

Responsive

@media (max-width: 700px) {
  .galeria {
    grid-template-columns: 1fr;
  }
}

Las media queries permiten adaptar la interfaz a distintos tamaños de pantalla.

Especificidad

En general, un selector por id tiene más peso que una clase, y una clase más que una etiqueta. La cascada también considera el orden de las reglas.
